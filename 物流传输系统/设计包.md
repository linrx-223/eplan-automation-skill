# 三段皮带运输机顺序控制系统 — EPLAN 电气设计包（课本版）

> 适用：电气自动化入门 / 对照教材「多条皮带运输机顺序控制」例题。
> 照这份包，可在 EPLAN Electric P8 里手画出一套完整、可交付的三段皮带顺序控制原理图。
> 配套仿真见同目录 `simulation.html`（打开即可看三段皮带联动）。

---

## 1. 系统概述（教材式）

三条皮带输送机 **M1 → M2 → M3** 首尾串联，组成一条物料运输线：物料从 M1 进料，经 M2 转运，由 M3 送出。

```
[进料]──PE1──▶[ M1 ]──PE2──▶[ M2 ]──PE3──▶[ M3 ]──PE4──▶[出料]
            KM1          KM2          KM3
```

这是教材里「运输机」章节的经典例题。核心控制要求是**逆物流方向启动、顺物流方向停止**，目的是：启动时下游先转、避免物料堆积在转运点；停止时上游先停、让皮带上现存物料被送走，不积压。

---

## 2. 控制要求（课本标准）

1. **启动（逆序，即逆物流方向）**：按启动后，**先 M3 转 → 延时 → M2 转 → 再延时 → M1 转**。本设计延时取 3 s / 段。
2. **停止（顺序，即顺物流方向）**：按停止后，**先 M1 停 → 延时 → M2 停 → 再延时 → M3 停**。本设计延时取 3 s / 段，确保物料被逐段送走。
3. **急停**：拍下急停按钮，三台电机**立即全部停机**，故障报警。
4. **过载保护**：任一台电机热继电器（FR1/FR2/FR3）跳闸，对应电机及**上游**立即停（防止继续送料），下游维持把现存物料运完；同时报警。
5. **堵料报警**：任一处转运点（PE2 / PE3）持续检测到有料超过 8 s，判定堵料，报警提示检查（电机不停，仅提示）。
6. **运行指示 / 故障指示 / 蜂鸣**：正常时绿灯亮；故障时红灯亮 + 蜂鸣。

> 与之前「两段接力」相比：本版为**三段**，且明确给出教材标准的「逆序启动 / 顺序停止」延时链，更贴近课本例题表述。

## 5. 控制逻辑（梯形图描述）

内部标志：`M0.0`=运行自锁；`M0.1`=停机顺停记忆；`T1/T2`=启动延时；`T3/T4`=停止延时；`T5/T6`=堵料计时。

**网络 1 — 运行自锁（任一保护断开即停机）**
```
M0.0 = ( M0.0 或 I0.0 ) 且 I0.1 且 I0.2 且 I0.7 且 I1.0 且 I1.1
```
> I0.1/I0.2 是 NC：正常=1，按下/拍下=0 → 自锁断开。FR 是热继电器 NC：跳闸=0 → 停机。

**网络 2 — 逆序启动（先 M3，延时 M2，再延时 M1）**
```
Q0.2 (KM3) = M0.0                                  // M3 立即转
T1: 当 M0.0 得电，计时 3s；T1.DN=1
Q0.1 (KM2) = M0.0 且 T1.DN                         // 3s 后 M2 转
T2: 当 M0.0 得电，计时 6s；T2.DN=1
Q0.0 (KM1) = M0.0 且 T2.DN                         // 再 3s 后 M1 转
```

**网络 3 — 顺序停止（先 M1 停，延时 M2，再延时 M3）**
```
M0.1 = ( M0.1 或 M0.0下降沿 ) 且 非( T3.DN 且 T4.DN )
   → 停止瞬间 M0.1 置位，维持 M2/M3 运转
Q0.0 (KM1) = M0.0                                  // M1 立即停（不自锁顺停）
T3: M0.1 得电计时 3s → T3.DN
Q0.1 (KM2) = M0.0 或 ( M0.1 且 非 T3.DN )          // M1停 3s 后 M2 停
T4: M0.1 得电计时 6s → T4.DN
Q0.2 (KM3) = M0.0 或 ( M0.1 且 非 T4.DN )          // M2停 3s 后 M3 停
```

**网络 4 — 故障与报警**
```
急停/任一过载 → M0.0=0，M0.1=0，Q0.0=Q0.1=Q0.2=0，HL2=1，HA=1
```

**网络 5 — 堵料报警（不停车，仅提示）**
```
PE2 持续有料 > 8s（T5） 或 PE3 持续有料 > 8s（T6） → HL2=1，HA=1
```
```
Q0.3 (HL1运行) = M0.0
Q0.4 (HL2故障) = 故障 或 堵料
Q0.5 (HA蜂鸣)  = 故障 或 堵料
```

### 动作时序一览

| 事件 | M1 | M2 | M3 | 备注 |
|---|---|---|---|---|
| 按启动 | 6s 后转 | 3s 后转 | 立即转 | 逆序启动 |
| 正常运行 | 转 | 转 | 转 | 物料顺流 |
| 按停止 | 立即停 | 3s 后停 | 6s 后停 | 顺序停止 |
| 拍急停 | 立即停 | 立即停 | 立即停 | 全停+报警 |
| M3 过载 | 立即停 | 立即停 | 立即停 | 全停+报警 |
| M1 过载 | 立即停 | 维持 | 维持 | 上游停、下游运完 |
| 转运点卡料>8s | 转 | 转 | 转 | 仅报警提示 |

## 6. EPLAN 手画步骤（Electric P8）

> 基于已装好的 EPLAN 2.9 SP1。新建项目即可，不必动现有 `D:\EPLAN\项目\`。

1. **建项目**：菜单「项目 → 新建」，取名 `物流传输_三段顺序`，模板选 `EEE_uni` 或默认，确定。
2. **建页结构**：在项目管理器新建页，建议 5 页：
   - 页 `=CA` 封面/目录（可空）
   - 页 `=P1` 主电路（电源 → QF → KM1~KM3 / FR1~FR3 → M1~M3）
   - 页 `=P2` PLC I/O 接线（传感器/按钮 → PLC 输入；PLC 输出 → KM/指示灯/蜂鸣器）
   - 页 `=P3` PLC 程序（用「PLC 盒」画梯形图网络 1–5）
   - 页 `=P4` 端子/电缆（可选）
3. **主电路（=P1）**：放断路器 `QF` → 三根分支各串 `KM1/FR1/M1`、`KM2/FR2/M2`、`KM3/FR3/M3`；电机画三相符号。注意 FR 的**常闭辅助触点**要引到控制回路（对应 I0.7/I1.0/I1.1）。
4. **I/O 接线（=P2）**：
   - 输入侧：SB1(NO)、SB2(NC)、SB0(NC)、PE1~PE4(NO)、FR1~FR3(NC) 接到 PLC `I0.0–I1.1`，公共端接 24V/0V。
   - 输出侧：Q0.0→KM1、Q0.1→KM2、Q0.2→KM3、Q0.3→HL1、Q0.4→HL2、Q0.5→HA（线圈回路加各自电源）。
5. **PLC 程序（=P3）**：用 PLC 盒按第 5 节网络 1–5 画梯形图；变量地址严格对应第 4 节 I/O 表。
6. **编号与校验**：「项目数据 → 消息」跑一次，消除"未连接/重复地址"类错误；导出 PDF 前先「项目 → 导出 → PDF」。
7. **对照仿真**：打开同目录 `simulation.html`，点「启动」看联动，再回 EPLAN 核对逻辑一致。

> 新手提示：NC 触点（停止/急停/热继电器）在 EPLAN 里选"常闭"变体；NPN 传感器按"有料=1"接法，不要接反。

---

## 7. 与仿真对照

`simulation.html` 把上面的逻辑做成可点按钮的动画：
- 「启动」→ M3 先转、3s 后 M2 转、再 3s 后 M1 转（逆序启动）；
- 料从 PE1 进、过 PE2/PE3 转运点、从 PE4 出并计数；
- 「停止」→ M1 立即停、3s 后 M2 停、再 3s 后 M3 停（顺序停止）；
- 「急停」或勾选"过载"→ 全停+红灯报警；
- 若某转运点持续有料 > 8s → 堵料报警（电机不停）。

设计包与仿真地址完全一致，可互相印证。
